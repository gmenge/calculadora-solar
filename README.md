# Calculadora Solar

Calculadora web de investimento e retorno em energia solar, publicada em
<https://gmenge.github.io/calculadora-solar/>.

Feita com HTML, CSS e JavaScript, em um único arquivo.

Os resultados são estimativas e usam tarifa e preços fixos no código.
